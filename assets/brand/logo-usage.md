# Logo Usage

---

## Primary Logo

House + integrated 0x + two people.

Use whenever possible.

---

## Horizontal Logo

Use in README banners.

---

## Logo Mark

Use for:

- App icon
- GitHub avatar
- Documentation

---

## Favicon

Simplified logo mark.

---

## Clear Space

Leave at least one logo height of empty space around the logo.

---

## Don't

❌ Stretch

❌ Rotate

❌ Add shadows

❌ Change colours

❌ Place on busy backgrounds

---

## Preferred Backgrounds

Midnight

White

Light Grey

## File Types

SVG

Primary format.

PNG

Fallback.
